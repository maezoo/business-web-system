# business-web-system

동감행정사사무소 사용자 중심 리뉴얼 프로토타입입니다.

## 핵심 설계 방향

- 내부 업무명 중심 IA를 **서비스 / 업무사례 / 상담 / 소개** 중심으로 재구성
- 전문 행정정보를 **상황 판단 → 핵심 정보 → 사례 → 상담** 흐름으로 재구성
- 해결사례와 갤러리를 **업무사례 아카이브**로 통합하는 UI 제안
- 자유 입력 문의게시판 대신 **단계형 맞춤 상담 플로우** 구현
- 모바일에서 큰 이미지보다 정보와 CTA를 우선하도록 반응형 설계
- 전화 상담을 단순 CTA가 아니라 서비스 과정의 일부로 연결

## 실행

별도 빌드 없이 `index.html`을 열면 됩니다.

## 참고

맞춤 상담은 현재 프론트엔드 프로토타입이며 서버로 정보를 전송하지 않습니다. 실제 운영 시 DB, 알림, 관리자 페이지 등의 백엔드 연동이 필요합니다.
